# Contributing to Oxyde RT  

Oxyde RT is a community-driven project to bring back the nostalgic charm of early 2000s desktops, built with modern tooling. Every bug report, feature request, and pull request helps keep the retro spirit alive.  

---

## 📖 How to Contribute

### 1. Reporting Issues  
- Use the **Issues** tab to report bugs, request features, or suggest improvements.  
- Please check if an issue already exists before opening a new one.  
- When reporting a bug:  
  - Include your **Linux distro**, **kernel version**, and any **error logs** if available.  
  - Describe the steps to reproduce the issue.  

### 2. Suggesting Features  
- Clearly describe what you’d like to see.    
- Screenshots, mockups, or references are highly encouraged.  

### 3. Code Contributions  
- Fork the repo and create a new branch:  
  ```bash
  git checkout -b 0xy1de/Oxyde-RT
